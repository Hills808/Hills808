### AI Visual Assistant

**Visiora AI** is an academic project focused on developing an AI-powered visual assistant for people with visual impairment.

The system connects **camera input, a C# backend, AI image analysis and audio feedback**.

<div align="center">

```text
┌──────────────┐
│    CAMERA    │
│ IMAGE INPUT  │
└──────┬───────┘
       │
       ▼

│       C#       │
└───────┬────────┘
        │
        ▼
┌────────────────┐
│   AI ANALYSIS  │
│     OPENAI     │
└───────┬────────┘
        │
        ▼
┌────────────────┐
│ CONTEXT / JSON │
└───────┬────────┘
        │
        ▼
┌────────────────┐
│ AUDIO FEEDBACK │
└────────────────┘
```

</div>

### Why Visiora represents my direction

The project brings together several areas that define the path I'm pursuing:

```text
C#  →  Backend  →  APIs  →  AI  →  Real-world application
```

During development, I explored challenges such as **continuous analysis, contextual responses, audio interaction and environment awareness**.
